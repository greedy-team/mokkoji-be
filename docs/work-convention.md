# 작업 컨벤션

* 커밋 메시지 · 이슈 제목 · PR 제목에 공통으로 쓰는 규칙.

## 형식

```
작업코드: 작업내용
```

ex) `Feat: 로그인 api 생성`

## 작업 코드

| Type     | 설명                            |
|----------|-------------------------------|
| Feat     | 기능 생성/변경/제거                   |
| Refactor | 코드 구조 개선 (기능 변동 없음)           |
| Fix      | 버그 수정 (기능 변동 없음, 의도된 동작으로 복구) |
| Hotfix   | 운영 환경 긴급 장애 대응용 수정            |
| Docs     | 문서 작성/수정 (README.md 등)        |
| Test     | 테스트 코드 추가/수정                  |
| CI/CD    | 빌드, 배포 관련 작업                  |
