# 실행 절차

## 1. 변경사항 파악

* 아래 명령어를 병렬로 동시에 실행
    * `git status` (변경/스테이징/추적되지 않은 파일 확인)
    * `git diff HEAD --stat` (변경 규모 확인)
* 변경 내용 판단에 필요하면 `git diff <파일>`로 상세 확인

## 2. 커밋 단위 그룹핑

* `docs/work-convention.md` 참고하여 커밋 메시지 생성
* 변경 파일들을 목적별로 그룹핑하여 커밋 단위 결정
    * 하나의 커밋 = 하나의 목적
    * 기능과 그 기능에 종속된 부속 파일(설정 등)은 같은 커밋으로 묶기

## 3. 초안 작성

- 초안을 `.claude/tmp/commit_draft.md`에 저장 (Write 도구가 폴더를 자동 생성하므로 mkdir 불필요)
- 초안 파일 형식 (커밋 단위마다 아래 블록 반복, 블록 사이는 빈 줄 1개):
    * 1번째 줄: `작업코드: 작업내용` (커밋 메시지)
    * 2번째 줄부터: 포함할 파일 경로를 한 줄에 하나씩
- 커밋 순서는 의존 관계가 자연스럽도록 배치 (참조되는 문서/설정이 먼저)

## 4. 초안 확인 및 선택지 제시

* [사용자 화면]
  ```
  (초안 파일 내용을 코드블록으로 표시)

  📄 [.claude/tmp/commit_draft.md](.claude/tmp/commit_draft.md)

  원하시는 작업을 선택해주세요. ex)1

  [1] 커밋 실행

  [2] 취소

  (수정은 채팅으로 요청 or 파일 직접 수정)
  ```
* 선택지 각 줄 사이의 빈 줄을 유지한 채 그대로 출력 (마크다운에서 단일 줄바꿈이 합쳐지는 것 방지)

## 5. 전처리

- Read 도구로 `.claude/tmp/commit_draft.md`를 최신 내용 로드
    * 이전 대화 컨텍스트에 있는 초안 내용을 그대로 신뢰하지 않음 (사용자가 파일을 직접 수정했을 수 있음).
    * 커밋 메시지·파일 범위 모두 파일 내용 기준으로 반영

## 6. 선택처리

* 사용자의 숫자(1/2) 또는 문구 답변에 따라 분기

### [1] 커밋 실행

1. 초안 파일의 커밋 단위별로 해당 파일만 `git add` 후 순서대로 커밋
2. 완료 후 생성한 커밋의 제목 나열

### [2] 취소

1. `rm .claude/tmp/commit_draft.md` 실행하여 초안 파일 삭제
2. 종료

### 그 외 문구 답변 (수정 요청)

1. 요청한 수정사항을 초안 파일에 반영
2. 4번으로 복귀

## 7. 임시 파일 정리

- 커밋 완료 후 `rm .claude/tmp/commit_draft.md` 실행하여 초안 파일 삭제
