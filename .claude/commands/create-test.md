# 실행 절차

- 구현이 끝난 변경사항을 대상으로 테스트를 작성·정비하고 컴파일까지 확인한다.

## 1. 테스트 코드 생성 및 실행

* 이번 구현으로 추가/변경된 코드에 대한 테스트 코드를 작성한다.
* 테스트를 실행해 통과 여부를 확인한다.
* 단위 테스트, 통합 테스트를 생성한다.
* 실패 시 원인을 진단해 수정하고 재실행.

## 2. 수정 범위 관련 테스트 정비

* 이번 수정으로 영향받는 기존 테스트를 찾아 함께 수정한다.
    * 변경한 클래스/메서드를 참조하는 테스트, 시그니처·동작 변경으로 깨지는 테스트를 확인
* 수정건과 관련 테스트를 다시 실행하고 모두 통과하는지 확인한다.

## 3. 컴파일 체크

* `./gradlew compileJava compileTestJava`로 메인·테스트 소스가 정상 컴파일되는지 확인한다.
* 컴파일 오류가 있으면 원인을 수정하고 다시 확인한다.
